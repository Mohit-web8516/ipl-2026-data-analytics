IPL 2026 Analytics — Data Audit¶

Project Objective¶

This project analyzes the IPL 2026 season using ball-by-ball cricket data.

The complete workflow will cover:

  1. Data Audit
  2. Data Cleaning
  3. Exploratory Data Analysis
  4. Power BI Dashboard
  5. Documentation and Recruiter Story

Data Strategy¶

The deliveries.csv file is treated as the primary source of truth for season-level analysis because it contains ball-by-ball data for the complete 2026 season.

The matches.csv file contains additional match-level information, but it does not contain the complete season.

This notebook only audits the raw data. No permanent cleaning or modification is performed here.
